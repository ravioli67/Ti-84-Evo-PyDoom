# DOOM for TI-84 Evo

A Python-based, DOOM-inspired first-person raycasting game for the TI-84 Evo graphing calculator.

Project Structure
src/DOOM.py — Main game source code.
docs/ — Documentation, technical notes, and development references.
Goals
First-person raycasting graphics
Keyboard-controlled movement and turning
Minimap and wall collision
Enemies, weapons, and health as development progresses
Compatibility with the TI-84 Evo Python environment
Requirements
TI-84 Evo graphing calculator
Python support and compatible TI drawing/system libraries
Status

Early prototype. Calculator-specific graphics APIs, input codes, and performance must be tested on the actual TI-84 Evo.

Running

Transfer src/DOOM.py to the calculator using a compatible TI file-transfer workflow, then run it from the calculator's Python application.
